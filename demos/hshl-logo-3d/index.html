🛑 p5.js (Immediate Mode / WebGL)

Keine Vektor-Extrusion. Jeder Block muss aus 3 einzelnen Quadern zusammengebaut werden:

// draw() - muss jeden Frame neu aufgerufen werden
p.ambientLight(100);
p.directionalLight(255, 255, 255, 0.5, 0.8, -1);
p.specularMaterial(50);

// Linker U-Block aus 3 Quadern:
p.push();
p.fill(leftColor);
// 1. Vertikaler Schenkel
p.push(); p.translate(-23.5, 0, 0); p.box(17, 32, 16); p.pop();
// 2. Oberer Balken
p.push(); p.translate(-8.5, 9.5, 0); p.box(13, 13, 16); p.pop();
// 3. Unterer Balken
p.push(); p.translate(-8.5, -10, 0); p.box(13, 12, 16); p.pop();
p.pop();

✅ Three.js (Retained Mode / Scenegraph)

Exakter 2D-Pfad aus dem CI-Manual wird deklarativ mit Fasung (Bevel) extrudiert:

// Einmalige Initialisierung:
const leftShape = new THREE.Shape();
leftShape.moveTo(-32, -16);
leftShape.lineTo(-32, 16);
leftShape.lineTo(-2, 16);
leftShape.lineTo(-2, 3);
leftShape.lineTo(-15, 3);
leftShape.lineTo(-15, -4);
leftShape.lineTo(-2, -4);
leftShape.lineTo(-2, -16);

// Echtes 3D-Mesh mit gerundeten Kanten & PBR:
const geometry = new THREE.ExtrudeGeometry(leftShape, {
  depth: 16, bevelEnabled: true, bevelThickness: 1.5
});
const material = new THREE.MeshStandardMaterial({
  color: leftColor, roughness: 0.25, metalness: 0.15
});
scene.add(new THREE.Mesh(geometry, material));
